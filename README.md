# رحلة القيم الأسرية — تطبيق الويب وخادم البيانات

تطبيق ويب تقدمي (PWA) وخادم بيانات مصغر لرحلة القيم الأسرية — إعداد: محمد كليب، جمعية سعداء للتنمية الأسرية.

## المميزات الجديدة
1. **بوابة تسجيل الأسرة (Onboarding Gate):**
   - حجب المحتوى وقيمة المسؤولية وأفراد الأسرة للزائر الجديد.
   - نموذج تسجيل بسيط يتطلب فقط: **اسم العائلة** و**رقم هاتف سعودي** (`05xxxxxxxx`).
   - تحقق فوري من صحة رقم الجوال السعودي.
   - حفظ بيانات العائلة محلياً وإرسالها إلى قاعدة البيانات MongoDB.
2. **نظام تتابع الأسابيع (Sequential Weekly Progression):**
   - في صفحة أنشطة المسؤولية، الأسبوع الأول مفتوح تلقائياً.
   - الأسابيع (2، 3، 4) مقفلة بـ 🔒 ولا يمكن إنجازها أو التعديل عليها إلا بعد إنهاء مهام الأسبوع السابق بنجاح.
3. **الربط مع MongoDB:**
   - خادم مدمج `server.js` (يعمل مباشرة عبر Node.js بدون مكتبات خارجية مطلوبة محلياً).
   - حفظ تسجيلات العائلات في قاعدة بيانات MongoDB في جدول `families`.
   - نظام حفظ احتياطي محلي في ملف `families_db.json` يضمن عمل التطبيق حتى دون اتصال بالإنترنت.
   - دالة سحابية جاهزة `api/register.js` للنشر على Vercel أو Netlify.

## التشغيل محلياً

### 1. تشغيل خادم Node.js مع الربط بقاعدة البيانات:
```bash
node server.js
```
ثم افتح المتصفح على: `http://localhost:3000`

### 2. إعداد رابط MongoDB:
انسخ ملف `.env.example` إلى `.env` وضع رابط الاتصال الخاص بكم:
```env
PORT=3000
MONGODB_URI=mongodb+srv://<username>:<password>@cluster0.mongodb.net/qiyam?retryWrites=true&w=majority
```

## مسارات الـ API
* `POST /api/register`: تسجيل عائلة جديدة (يستقبل `{ familyName, phone }`).
* `GET /api/families`: عرض عدد وقائمة العائلات المسجلة.
* `GET /api/health`: فحص حالة السيرفر وقاعدة البيانات.

## النشر السحابي (Deployment)
* **Vercel / Netlify:** ارفع المشروع كما هو، وأضف متغير البيئة `MONGODB_URI` في لوحة تحكم المنصة.
* **استضافة خاصة (VPS / cPanel):** شغّل السيرفر عبر `node server.js` أو مدير العمليات PM2.
